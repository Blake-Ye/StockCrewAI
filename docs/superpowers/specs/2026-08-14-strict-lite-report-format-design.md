# 严格版精简投资研究报告设计

## 目标

在现有 StockCrewAI 单公司报告基础上，将读者可见正文扩展约 30%，重点解决章节混杂、口径混杂、图表缺少研究问题和技术元数据干扰阅读的问题。本次不新增预测、市场共识、正向 DCF、目标价、仓位或额外 LLM 调用。

## 设计原则

1. 正文遵循“研究问题 → 数据 → 图表 → 观察 → 投资含义 → 限制与反证 → 本节结论”。
2. FY、YTD、TTM 与市场时点分别展示，不在同一趋势表或图中无说明混用。
3. LLM 只提供克制连接语；数字、表格、结论标签和口径说明由确定性 Python Renderer 注入。
4. 缺少可选字段时隐藏对应行或显示“数据不足”，不补造数据，也不阻断其余可靠章节。
5. 正文不输出买入、卖出、持有、目标价或仓位建议。
6. 保留三张分析图片，不新增依赖和装饰性图片。

## 固定章节

0. 封面与研究元数据
1. 一页结论
2. 公司与研究范围
3. 最新经营状态
4. 历史经营与财务质量
5. 估值
   - 当前估值
   - 相对自身历史估值
   - 反向 DCF
6. 主要风险与监控条件
7. 综合判断与重新评估条件
8. 数据来源、方法与技术附录
9. 非投资建议声明

## 章节内容

### 封面与研究元数据

使用表格展示公司名称、Ticker、证券类型、当前价格与时间戳、报告日期、数据截止、研究期限、财务口径和报告版本。只使用现有 ReportContext 字段；没有可靠值时显示“数据不足”。

### 一页结论

保留四项确定性摘要：经营质量、相对自身历史估值、市场隐含预期、研究动作。增加“判断依据”与“关注条件”，但不重复后文全部指标。

### 公司与研究范围

展示法律主体可用名称、Ticker、证券/报告 Profile、研究期限、净现金或净债务、股份变化及范围限制。不得由 LLM 生成分部、行业或竞争事实。

### 最新经营状态

YTD 指标、TTM 规模和完整 FY 严格分开。现有核心财务图保留三个面板，分别回答增长与资本配置、盈利能力、现金流质量。每组图提供图号、问题、期间、单位、来源、截止日期、观察、投资含义和限制。

### 历史经营与财务质量

新增五个共同完整 FY 的核心数据表。表格按年列出营业收入、净利润、经营现金流、资本开支、自由现金流及稀释股份数中实际可用的项目，并在表后列出收入、净利润和 FCF CAGR。完整财年趋势图使用 FY2021=100 的指数化共同纵轴，不再用三个独立纵轴比较不同量级。

### 估值

当前估值、历史估值和反向 DCF 放在同一大章的三个独立小节。历史估值只说明相对自身历史位置；反向 DCF 明确以 TTM FCF 为模型起点，和完整 FY FCF CAGR 仅作方向性比较。

### 风险与结论

正文风险固定为前三项，并以“风险、影响路径、监控指标、来源”表格展示。其余风险保留折叠附录。综合判断只复述结论链和重新评估条件，不重复整份报告数字。

### 技术附录

status、Profile、Policy version、Gate/Claim 状态、判断规则、数据口径和术语全部移至技术附录，不出现在一页结论。

## 图表规范

每张图前提供研究问题及必要性；图后提供观察、投资含义、限制与反证。图注必须包含图号、期间、单位、数据来源、数据截止和 Actual/YTD/TTM 口径。历史趋势图使用统一指数纵轴；历史 P/E 图保留当前值与分位参考线。

## 非目标

- 不增加正向 DCF、财务预测、目标价或概率加权估值。
- 不增加市场共识、可比公司、行业规模或催化剂数据源。
- 不改变 Flow、Crew 数量、Agent 数量、Gate、SEC/Yahoo 工具或估值公式。
- 不增加 LLM 调用次数或 Python 依赖。

## 验收标准

1. 正文严格按固定章节顺序输出。
2. 可见正文较现有报告增加元数据表、五年财务表、判断依据和风险监控表，但不存在空白模板章节。
3. FY、YTD、TTM 和市场时点均有明确标签。
4. 三张图片均存在且正文、图表读取同一 ReportContext。
5. 不出现重复摘要、旧总体判断或无来源因果解释。
6. 全套离线测试通过，真实 Apple 运行生成 `status=ok`、`stage=report` 的报告。

# 面向读者的正式报告设计

## 目标

将 `investment-report.md` 从可审计的原始结果清单改为普通读者可快速理解的中文研究报告：展示确定性 Verdict、统一数字格式、解释关键术语，并内嵌三张由已验证数据确定性生成的图表。

## 固定边界

- LLM 仍只生成九段无数字叙述，不生成图、数字、评级或买卖建议。
- Python 是 Verdict、数字、术语、图表、Markdown 拼装和文件写出的唯一来源。
- 不升级 CrewAI、Python 或现有依赖；新增生产依赖仅为 `matplotlib`。
- 成功运行时，图表临时写入系统临时目录，转换为 Markdown data URI 后删除；项目根目录不新增图片目录或残留图片文件。
- 阻断、无效或缺少图表所需输入时，报告仍可生成，但只省略相应图表并保留已验证文字与数据。

## 报告内容

1. 执行摘要显示：研究状态、总体判断、经营质量、风险等级、规则触发原因；不显示机器化 `status=ready` 作为唯一结论。
2. “研究结论与行动参考”只显示确定性、非个性化的研究标签，例如“估值偏贵，等待更高安全边际”；不出现“买入、卖出、持有”等个性化交易指令，免责声明保留。
3. 术语说明使用固定中文文本：P/E（市盈率）、FCF Yield（自由现金流收益率）、TTM（过去十二个月）、DCF（现金流折现）、反向 DCF（由市场价格倒推隐含增长）。
4. 大额美元以“万亿美元”或“亿美元”显示，金额保留两位小数；倍数和百分比最多两位小数。
5. 财务质量与财务趋势不重复整组指标；有数值计算 Claim 被 Renderer 规范化展示时，不输出“无已验证 Claim”。

## 图表

- 核心财务指标图：收入增长、营业利润率、净利率、FCF 利润率、现金转换率、股份变化，位于执行摘要后。
- TTM 财务规模图：收入、营业利润、净利润、经营现金流、自由现金流，单位为亿美元，位于财务趋势章节。
- 五年历史 P/E 图：60 个月 point-in-time P/E、25/50/75 分位线与当前点，位于历史估值章节。历史工具必须返回逐月 `date` 与 `pe_ratio`，且当前值及报告日期均指向最新月份。

## 验收

- 成功报告包含“总体判断”、术语说明、三张 `data:image/png;base64,` 内嵌图和简洁格式化数字。
- 不包含“无已验证 Claim。”的错误提示或长 Decimal 串。
- 历史估值的 `current_value` 和报告显示日期均为 60 月序列的最新月份。
- 默认单元测试离线；全量测试、编译检查和一次真实 `crewai run` 均成功后才能交付。

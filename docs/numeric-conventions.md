# 财务数值约定

本文档只保留当前基本面研究主流程需要的财务计算约定。

## 1. 精度和缺失

- 财务金额、股数、价格、EPS、比率和审计计算的内部表示使用 `decimal.Decimal`。
- 不用 `float`、`NaN`、`Infinity` 或 0 表示缺失、不可适用或验证失败。
- 计算结果必须保留单位、币种、期间、来源 ID、公式版本和状态。
- 显示层可以舍入，但显示舍入不得回写原始计算值。

## 2. 当前公式

- `free_cash_flow = operating_cash_flow - capex`；`capex` 在公式中必须是正的投入金额。
- `market_cap = price × shares`；价格和股数必须属于可比的时间点并有来源。
- `P/E = price / diluted_eps`；EPS 非正或期间不匹配时返回 `unavailable`。
- `FCF_yield = free_cash_flow / market_cap`；必须在报告中注明自由现金流期间，九个月数据不能冒充全年或 TTM。

除非具体工具契约明确指定，计算不自动年化、不回填、不混合币种。负自由现金流是合法结果，不得强行改成正值。

## 3. 时间、单位和来源

点时数据要满足 `filed_at <= as_of`，并且观察日期不能晚于市场价格时间戳。期间保留起止日期、财年/季度和是否审计的信息。没有单位或币种证据时不自动乘除千、百万或转换汇率。

## 4. 失败语义

除数为零、单位未知、币种冲突、期间冲突、价格缺时间戳或 Evidence 未验证时，返回明确的 `unavailable`/`not_ready` 和稳定 `reason_code`。不能通过填 0 或使用旧值让 Gate 假装通过。
